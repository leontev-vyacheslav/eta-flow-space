# Flow Space Reporting

Reporting service for Eta Flow Space platform.

## Stack

- **FastAPI** - Async web framework
- **SQLAlchemy[asyncio]** - Async ORM
- **asyncpg** - Async PostgreSQL driver
- **WeasyPrint** - PDF generation

## Setup

```bash
# Create virtual environment
python3 -m venv .venv

# Activate virtual environment
source .venv/bin/activate

# Install the locked dependencies, then the dev tools
pip install -r requirements.lock
pip install -e ".[dev]"

# Copy and configure environment
cp .env.example .env

# Run the server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

## Dependencies

Direct dependencies are declared in `pyproject.toml`; `requirements.lock` pins the full
dependency tree with hashes and is what the Docker image installs. After changing
`pyproject.toml`, regenerate the lock and commit both files:

```bash
pip-compile --strip-extras --generate-hashes --output-file=requirements.lock pyproject.toml
```

## Fonts

Reports use Liberation Serif (metric-compatible with Times New Roman), bundled in
`app/templates/assets/fonts/` under the SIL Open Font License (`OFL.txt`) and loaded for
every report by `app/helpers/pdf.py`, so PDFs render the same in development and Docker.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/health-check` | Health check |
| `GET` | `/api/reports/device-state/{device_id}` | Generate device state PDF report |
